# Security Policy

## Supported versions

Security fixes are applied to the latest release and the current `main` branch.
Older versions are not maintained separately.

## Reporting a vulnerability

Use **Report a vulnerability** on the repository's **Security** tab to submit a
private report. Do not disclose a suspected vulnerability in a public issue,
discussion, or pull request.

Include the affected version, impact, reproduction steps, and any suggested
mitigation. Please remove portal URLs, email addresses, company names, cookies,
tokens, OTP values, ICA files, browser profiles, traces, screenshots, and other
authentication or deployment material before submitting a report.

If private vulnerability reporting is temporarily unavailable, use the
maintainer's GitHub profile contact options without including sensitive details
and request a private reporting channel.

You can expect an acknowledgement within seven days. Please allow time for a fix
before publishing details.

## Scope

Reports about this launcher's configuration handling, browser automation,
download validation, local file handling, or macOS application wrapper are in
scope. Vulnerabilities in Citrix Workspace, Playwright, PingID, or another
third-party service should also be reported directly to that vendor.

Only test systems and accounts you are authorized to access. Never include real
credentials or authentication material in a security report.
